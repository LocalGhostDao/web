LocalGhost server , https://github.com/LocalGhostDao/localghost

The server set is LocalGhost's own release, copied unmodified from the GitHub release of the same
tag, the bundle (the daemons and the operator tools, built from the tag by tools/release_build.sh
with CGO off, -trimpath and no build id, so cutting the same tag again gives the same bytes),
RELEASE.txt (the version, name, commit, date and changes the phone shows before anything is
downloaded) and NOTES.md (what the release does and what it doesn't yet).
